# modbus-slave на Windows: скачать и запустить

`modbus-slave` — эмулятор датчиков Modbus. Он отвечает за датчики по RS-485 (через USB-адаптер) или по Modbus TCP,
а датчиками управляют с веб-страницы. Установка не нужна: это один файл `.exe`.

Проверено на Windows 10 и 11.

## 1. Скачать

1. Откройте страницу <https://github.com/lab240/modbus-slave/releases/latest>.
2. В разделе **Assets** скачайте `modbus-slave.exe`.
3. Создайте папку, например `C:\modbus-slave`, и переложите файл туда.

Браузер может предупредить, что файл «скачивают редко». Выберите «Сохранить» (в Edge: «…» → «Сохранить» →
«Всё равно сохранить»).

## 2. Подключить адаптер (если нужен RS-485)

Без адаптера тоже можно: датчики будут отвечать по Modbus TCP (шаг 4, вариант А).

1. Вставьте USB-RS485 адаптер **прямо в разъём компьютера**, не через USB-хаб.
2. Откройте **Диспетчер устройств** (правой кнопкой по «Пуск» → «Диспетчер устройств») → **Порты (COM и LPT)**.
   Там появится строка вроде `USB Serial Port (COM5)`. Запомните номер: `COM5`.

Если порта нет, а в списке есть устройство с жёлтым значком, поставьте драйвер адаптера. Для адаптеров на FTDI это
«VCP driver» с сайта ftdichip.com.

## 3. Открыть PowerShell в папке с программой

Откройте папку `C:\modbus-slave` в Проводнике и щёлкните правой кнопкой по пустому месту:
- Windows 11: «Открыть в Терминале»;
- Windows 10: с нажатой клавишей **Shift** → «Открыть окно PowerShell здесь».

Если просто дважды щёлкнуть по `modbus-slave.exe`, откроется окно с подсказкой и примерами. Это нормально:
программе нужны параметры. Окно закроется после нажатия Enter.

## 4. Запустить

Вставляйте команду целиком, одной строкой.

**Вариант А: без железа, по Modbus TCP.** Четыре датчика температуры и влажности KTH2-R с адресами 1–4 на порту 1502:

```powershell
.\modbus-slave.exe --tcp :1502 --profile kth2r --units 1-4 --api 127.0.0.1:8650
```

**Вариант Б: на COM-порту.** Те же датчики на `COM5`, 9600 бод, 8N1 (подставьте свой номер порта):

```powershell
.\modbus-slave.exe -p COM5 -b 9600 --profile kth2r --units 1-4 --api 127.0.0.1:8650
```

При первом запуске Windows может показать:
- **«Windows защитил ваш компьютер»** → «Подробнее» → «Выполнить в любом случае»;
- **запрос брандмауэра** (для варианта А) → «Разрешить доступ», иначе датчики не будут видны с других компьютеров.

Пока программа работает, окно PowerShell должно оставаться открытым. Остановить программу: **Ctrl+C**.

## 5. Открыть страницу

Откройте в браузере <http://127.0.0.1:8650> или выполните во втором окне PowerShell:

```powershell
start http://127.0.0.1:8650
```

На странице:
- плитки датчиков с текущими значениями; значения можно менять;
- переключатель **TCP / RTU** и выбор COM-порта, скорости и чётности у каждого датчика;
- добавление и удаление датчиков, просмотр и запись регистров;
- готовые команды `modpoll` и `mbpoll` для опроса выбранного датчика (под строкой «Функции: 03 …»).

## 6. Проверить опросом

Подойдёт любой Modbus-мастер: SCADA, контроллер, шлюз или программа `modpoll` (скачивается с modbusdriver.com,
файл `modpoll.exe` из папки `win`).

Температура и влажность KTH2-R по Modbus TCP, датчик 1:

```powershell
.\modpoll.exe -m tcp -p 1502 -a 1 -t 4 -r 769 -c 2 127.0.0.1
```

По RS-485, если мастер подключён ко второму адаптеру на `COM6`:

```powershell
.\modpoll.exe -m rtu -b 9600 -p none -a 1 -t 4 -r 769 -c 2 COM6
```

Первое число — температура в десятых долях градуса (`215` = 21,5 °C), второе — влажность в десятых долях процента.

## 7. Страница с других компьютеров

По умолчанию страница открывается только на этом компьютере. Чтобы открыть её с другого компьютера, запустите
программу с адресом `0.0.0.0` и токеном (паролем страницы), например `678876`:

```powershell
.\modbus-slave.exe --tcp :1502 --profile kth2r --units 1-4 --api 0.0.0.0:8650 --api-token 678876
```

Откройте порт 8650 в брандмауэре (один раз, в PowerShell **от имени администратора**):

```powershell
netsh advfirewall firewall add rule name="modbus-slave 8650" dir=in action=allow protocol=TCP localport=8650
```

На другом компьютере откройте `http://<IP этого компьютера>:8650`; IP покажет команда `ipconfig`. Страница один раз
спросит токен. Чтобы сменить токен, остановите программу (Ctrl+C) и запустите её с новым `--api-token`; страница
спросит токен заново.

## Если не работает

| Что видно | Что сделать |
|---|---|
| `Access is denied` при открытии COM-порта | Порт занят другой программой (терминал, SCADA, второй экземпляр modbus-slave). Закройте её. |
| Список портов на странице пуст | Адаптер не вставлен или нет драйвера: проверьте «Порты (COM и LPT)» в Диспетчере устройств. |
| Мастер получает тайм-ауты | Проверьте, что у мастера и датчика совпадают скорость и чётность, а адрес мастер опрашивает из 1–4. Поменяйте местами провода A и B. Вставьте адаптер без хаба. |
| Страница не открывается с другого компьютера | Нужны `--api 0.0.0.0:8650`, токен и правило брандмауэра из раздела 7. |
| Окно закрывается сразу после запуска | Запускайте из PowerShell (шаг 3), а не двойным щелчком: тогда видно сообщение об ошибке. |

Все параметры: `.\modbus-slave.exe --help`. Список встроенных датчиков: `.\modbus-slave.exe --list-profiles`.
